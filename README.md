# Smithgentic Browser

A Chrome/Edge extension that reads and acts on web pages with the model of your choice.

## Install from source

1. Clone the repository:

   ```bash
   git clone https://github.com/Yashsmith/Smithgentic_Browser_Ext.git
   ```

2. Open `chrome://extensions` in Chrome, or `edge://extensions` in Edge.

3. Turn on **Developer mode**.

4. Click **Load unpacked** and select the entire cloned `Smithgentic_Browser_Ext` folder.
   

5. Pin **Smithgentic Browser**, then click its icon or press `Cmd+E` on macOS / `Ctrl+E` on Windows and Linux.

6. Open **Settings** and add a model provider and API key.

Requires Chrome/Edge 116 or newer.
